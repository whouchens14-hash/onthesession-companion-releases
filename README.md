# OnTheSession Studio Companion — installers

This repository holds **only the finished installers** for the OnTheSession
Studio Companion for macOS. The app's source code is private and is not here.

## Installing

1. Open the latest release on the right (**Releases**) and download the `.dmg`.
2. Open it and drag **OnTheSession Studio Companion** into **Applications**.
   Run it from Applications, not from the installer window — otherwise the
   Pro Tools features cannot get the permission they need.
3. The first time you open it, macOS asks whether to open an app downloaded
   from the internet. Click **Open**. The app is signed and notarized by Apple.

Works on Apple-silicon and Intel Macs running macOS 11 or later.

Connected features (requests, deliveries, credits, invoices) need an
OnTheSession account, which is by invitation.
